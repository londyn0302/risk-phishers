1.	Create a GitHub repository called SentinelAI.
2.	Everyone clones the repository.
3.	Install Node.js.
4.	Create the Express backend.
5.	Create one webpage with a text box and Analyze button.
6.	Send the entered text from the webpage to the backend.
7.	Create five or ten simple phishing rules.
8.	Calculate a score from 0–100.
9.	Return the score and detected warning signs.
10.	Display them on the website.
At that point you have your first working prototype.
